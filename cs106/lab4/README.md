# 23520199 - Assignment 4

## Prequisites

- Python 3.13+
- Google OR-Tools: [link](https://developers.google.com/optimization/install)

## Setup and Run

1. Clone the repository contains test cases for knapsack problem: [link](https://github.com/likr/kplib)
2. Rename the cloned folder to `test_cases` and place it in the same directory as `main.py`.
3. Run `main.py`:

```bash
 python main.py
```

4. The logs will be saved in `logs` folder.
